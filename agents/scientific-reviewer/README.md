# Scientific Reviewer

Reviews evidence bundles, reads quoted passages against claims and replays recorded analyses without changing the evidence.

## Install

Install science-evidence, science-literature and science-statistics first, then scientific-reviewer.

## Limits

Use public or synthetic data only. This agent gives no clinical, diagnostic, dosing or wet-lab instructions, starts no compute jobs and sends no notifications. Evidence is not stored in memory. Literature calls are serial and provider limits apply. Citation resolution does not establish claim support. Preprints are labelled and retracted sources do not support claims.

Provenance is tool-reported. Verification checks consistency only; it does not authenticate execution or validate a method. Replay recomputes registered methods; it does not prove suitability. A domain expert must accept method suitability. Agent behaviour has not yet been verified by live evaluation; this package is not published. Live evaluation is required before publishing.
