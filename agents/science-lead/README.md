# Science Lead

Frames computational biomedical questions and coordinates literature, bounded analysis, evidence verification and review into a traceable report.

## Install

Install science-evidence, science-literature and science-statistics first, then science-lead. To delegate, install literature-researcher, scientific-analyst and scientific-reviewer and add all three to the lead's delegation allow list. The lead can also work solo.

## Limits

Use public or synthetic data only. This agent gives no clinical, diagnostic, dosing or wet-lab instructions, starts no compute jobs and sends no notifications. Evidence is not stored in memory. Literature calls are serial; provider limits apply. Citation resolution does not establish claim support. Preprints are labelled and retracted sources do not support claims.

Analysis requires stated units, experimental unit, groups, missing-value policy and method. Reported numbers come from skill results. Repeated units are flagged; rows are treated as independent. The statistics skill does not calculate p-values or confidence intervals and does not establish causality.

Provenance is tool-reported. Verification checks consistency only; it does not authenticate execution or validate the method. A domain expert must accept method suitability. Agent behaviour has not yet been verified by live evaluation; this package is not published. Live evaluation is required before publishing.
