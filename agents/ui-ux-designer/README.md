# UI/UX Designer

Produces evidence-labelled UX flows, state and token specs, WCAG 2.2 AA annotations and testable handoff criteria.

## When to use

Pick this agent for evidence-labelled UX flows, interface states, design tokens, WCAG 2.2 AA annotations, and testable developer handoff criteria.

## Package and setup

- Version: **1.0.0**. Author: **Buildersoft LLC**. License: **MIT** (see `LICENSE`).
- Requires **Sophon 2.2.0 or newer** with repository, design, and browser tools enabled as needed.
- This is a persona package, not executable code. It installs no tools, integrations, or credentials.
- Accessibility targets and design instructions are not a certification or a substitute for QA.
- Delegation is disabled. Heartbeat, auto-approval, and autonomous planning are off on install.
- Models are inherited from the host. `SOUL.md` is the unmodified existing local agent persona.

Install through Sophon's agent package import, or `sophon agents install <package-file>`.
Choose a free ID if `ui-ux-designer` already exists. Packaged agents are third-party under
Sophon's trust rules: select or delegate explicitly; standing auto-approvals do not apply.
