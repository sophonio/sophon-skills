# Literature Researcher

Searches and screens public scientific literature, returns source identifiers and quotes passages with locators for claim review.

## Install

Install science-evidence, science-literature and science-statistics first, then literature-researcher. This agent requires science-evidence and science-literature.

## Limits

Use public or synthetic data only. This agent gives no clinical, diagnostic, dosing or wet-lab instructions, starts no compute jobs and sends no notifications. Evidence is not stored in memory. Literature calls are serial and provider limits apply; PubMed provides abstracts, not full text. Citation resolution does not establish claim support. Preprints are labelled and retracted sources do not support claims.

Provenance is tool-reported. Verification checks consistency only; it does not authenticate execution or validate a method. A domain expert must accept method suitability. Agent behaviour has not yet been verified by live evaluation; this package is not published. Live evaluation is required before publishing.
