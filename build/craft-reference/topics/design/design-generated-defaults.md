# Generated-looking defaults: the dated catalogue

Dated 2026-11. These are the choices generators reach for first, so a page made of them reads as made by nobody in particular. The list moves with every model generation: an entry recommended in one year becomes a tell in the next. The user's words and a system the user chose always take precedence over this list, and an entry that fits the product on purpose is fine. Every row pairs the default with a repair, because a ban with no positive move invites the nearest substitute.

## Type

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| Inter, Roboto, Arial or a bare system stack as the display face | the most frequent pick | a chosen system names it; an operate surface where the platform face is right | a face chosen for the product's voice, or the system face with real hierarchy |
| Space Grotesk as the "distinctive" face | the usual second pick | the brand already uses it | a face from the product's own world |
| A thin serif display with one italic or coloured word | a fashion of generated landing pages | an editorial brand set it on purpose | one face at a real weight; emphasis by structure |
| A tracked all-caps eyebrow over every heading | template chrome | one category label where it informs | the heading alone, left-aligned |
| Monospace as a costume for "technical" | signals tech without content | code, ids, numbers that line up | the interface face; mono for data only |
| Hierarchy by size alone | many sizes, no system | never as the only cue | weight, colour and space carry hierarchy; fewer sizes |
| Gradient text | decoration in place of emphasis | a logo the user supplied | solid colour; weight or size for emphasis |
| Meta strings joined by middle dots | template chrome | a real byline of a publication | labelled fields, or one plain sentence |

## Colour

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| Purple or violet gradients on white | the strongest single tell | the brand colour is violet, used flat | flat surfaces; colour only where it means something |
| Cream paper, a serif and a terracotta accent | a whole look reached for by default | a brand that already owns it | a palette from the product's own materials and scene |
| Near-black with an acid green or neon accent | the "developer" default | a brand that already owns it | a calm dark with one accent that means something |
| Grey text on a coloured surface | looks washed out | never | tint secondary text from the surface hue, at 4.5:1 |
| Several accents, none with a meaning | colour as decoration | chart series with a legend | one accent with a stated meaning; neutrals for the rest |
| Dark or light picked by category | assumes the scene | a chosen system fixes it | pick from the scene of use; build both modes |
| Glow and glass panels | the default "premium" finish | a platform shell that uses it natively | opaque surfaces; depth by tone or a small shadow |

## Layout

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| Everything centred | the zero-decision layout | one short hero line, a dialog | left-aligned reading order; centre only a single statement |
| A grid of identical icon, heading and text cards | the feature-grid template | items truly equal and parallel | a table, or a list with a detail pane |
| Cards inside cards | boxes as the only structure | never | one container level; space and rules inside it |
| A strip of big headline numbers | filler that looks like data | numbers the user tracks daily | the numbers in context: a table, or beside their trend |
| 01 / 02 / 03 markers on things that are no sequence | fake order | real steps people follow in order | plain headings |
| One radius and one gap everywhere | no hierarchy | a system that defines one on purpose | scales that follow the hierarchy |
| A centred eyebrow, heading and lead on every section | the section template | one section that opens the page | left-aligned headings, one statement each |
| Hero, three features, testimonials, call-to-action band | the landing page template | never by default | sections that argue the product's own case in order |

## Components

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| A coloured bar down one side of a rounded box | the default "callout" | a system's own notification pattern | an icon and a word, or a full border |
| The same soft grey shadow on every element | no depth model | never | one depth strategy: borders, tone or shadow levels |
| Emoji as icons | quick filler | a chat or social product where people use them | one icon set at one size, with accessible names |
| Sparklines and progress rings as decoration | fake data | real series the user reads | real values, or nothing |
| A modal for every task | breaks context | a short confirmation | inline editing, a drawer, or a page |
| A clickable div | no keyboard, no role | never | a button or a link |
| An arrow after every link | template chrome | a single "next" link | the link text says where it goes |
| Window chrome with three coloured dots | invented product framing | a screenshot of a real window | the real interface, uncropped, or nothing |

## Imagery

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| People drawn in SVG, products drawn in CSS | stand-ins for real material | an illustration style the brand owns | real photographs or real screenshots the user supplies, or a labelled gap |
| Stock photos presented as the client's own | false content | labelled as illustrative | the client's images, or none |
| Gradient washes, blobs or meshes behind the hero | ambient decoration | never as the main visual | the product itself as the visual |
| A wall of look-alike or invented logos | invented proof | real customers who agreed | real logos with permission, or no wall |
| A caption explaining what a picture shows | the picture is not doing its job | data figures that need a source | a picture that needs no caption, or a factual caption |

## Motion

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| Fade-up of every section on scroll | the default entrance | one orchestrated first load | motion only where state changes |
| Hover lift on every card | the default hover | a card that is one large click target | a colour or border change on the target |
| transition: all | animates layout by accident | never | name the properties: transform, opacity |
| Ease-in entrances, growing from scale(0) | feels sluggish and unreal | never for UI | ease-out to enter; start from about 0.95 and fade |
| Bounce or elastic everywhere | playful by default | a playful, physical subject | a short ease-out |
| Animating actions used many times a day | slows the expert | never | no animation on frequent actions |
| Scroll-jacking | takes control from the reader | never | native scroll; scroll-bound visuals only |
| Numbers that count up | motion for its own sake | never | the final number at once |

## Copy

| Default | Why it reads as generated | Fine when | Repair |
|---|---|---|---|
| Seamless, elevate, unlock, robust, empower, leverage | the generator's vocabulary | never | the concrete verb: what the person does |
| Stock lines ("everything you need", "for teams of all sizes") | says nothing specific | never | a sentence only this product could say |
| "Not X, but Y" and "X. Y." headings | a rhythm generators repeat | once, when the contrast is the point | a plain statement of the claim |
| Runs of negations ("No setup. No code. No limits.") | the same rhythm | never | the one limit that matters, stated plainly |
| Virtue words without proof (powerful, intuitive, trusted) | claims with no evidence | never | the evidence: a number, a named capability |
| Invented numbers, quotes, customers or names | false content | never | real content, or a labelled gap |
| Submit, Continue, Learn more | vague labels | a multi-step form's real next step | the verb and object: "Book visit", "Save rule" |
